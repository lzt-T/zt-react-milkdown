## Context

动机见 proposal.md。`MilkdownEditor` 已根据属性解析文案，React 搜索栏和占位样式可以随渲染更新；但 `useMilkdownEditor` 的创建与清理依赖包含 `locale`，核心运行时只在初始化时把文案传给插件与 NodeView。斜杠菜单还在创建时按语言解析菜单项，因此移除生命周期依赖不足以完成修复。

本变更跨越 React 生命周期、核心运行时和自定义视图，需统一更新入口。复用既有依赖和 Portal 策略，不执行未经用户授权的 package.json 脚本，不进行浏览器控制。

## Goals / Non-Goals

**Goals:**
- 让文案同步与实例创建分离，更新不触碰文档事务、历史插件或搜索插件状态。
- 为已创建的视图提供文案刷新入口，保留节点和弹层中的输入、模式及焦点。
- 处理初始化完成前的属性变化，确保首次可交互界面使用最新配置。

**Non-Goals:**
- 不新增语言，不更换国际化库，不翻译用户文档或自定义斜杠菜单项。
- 不改变只读模式、快捷键模式、上传配置等其他属性的生命周期策略。
- 不重构无关插件，不迁移消费项目的依赖补丁，不修改 dist 或生成样式。

## Decisions

### 1. 核心运行时提供实例级文案同步方法

在 `MilkdownEditorRuntime` 增加统一同步入口，接收当前语言与已解析的完整文案。每个运行时持有独立文案对象，原位更新字段，让事件处理器和后续打开的弹层读取最新值；相同有效配置重复同步时跳过刷新。

文案仍由 `resolveEditorMessages` 按现有优先级解析。不修改共享语言包对象，不调用全局语言切换影响其他实例。独立对象在创建时复制，避免外部对象或资源包被原位修改。

备选方案：销毁后恢复 Markdown 无法保留历史；仅修改文案引用无法更新已经写入 DOM 或已传入 React 树的字符串。二者均不满足规格。

### 2. 只刷新承载文案的视图

文案原位同步后，通过直接函数调用通知相关插件视图和 NodeView 更新已有 DOM 标签、属性或以新 props 重渲染既有 React 根。刷新入口与视图生命周期绑定，在销毁时解除注册，避免引用失效视图。

不整体重装插件，不创建新的 EditorState，不批量销毁重建 NodeView。既有视图保留草稿、编辑模式、选区与焦点；刷新操作不调用 focus 或 scrollIntoView，不向历史写入事务。对已打开的图片等弹层，同样将文案更新接到其现有渲染入口，保留表单输入。

同模块内由运行时直接管理刷新回调，采用简洁的观察者关系；不引入全局事件总线。避免为每个字符串建立单独订阅。

备选方案：通过重建 PluginView 或 NodeView 强制更新可减少局部改动，但会丢失界面输入状态，并可能影响历史或搜索上下文，因此采用显式刷新。

### 3. 斜杠菜单独立更新语言派生数据

让 slash 初始化结果提供语言更新入口，在语言变化时重新解析内置菜单项与分组，并使用当前编辑器状态重新过滤和渲染。保留当前查询和可用高亮项；继续尊重自定义 items 和 enabled 配置。文案更新不改动快捷键定义或命令执行行为。

只更新通用文案对象无法改变初始化时已解析的菜单项，故该派生数据必须同步更新。

### 4. React Hook 使用初始化完成后的同步 effect

从实例创建及对应清理依赖中移除 `locale`，新增依赖当前语言、解析文案和 `editorInfo.loading` 的同步 effect；等待运行时可用后调用统一同步入口。这样初始化期间配置变化也会在 ready 后落到同一实例，无需为了语言变化引入额外组件状态。

保留现有 markdown 外部同步路径；国际化同步不得调用 setMarkdown、replaceAll 或初始化回调。

## Risks / Trade-offs

- [某些视图把文案提前展开为字符串] → 实施时逐个检查文案消费位置，覆盖现有 DOM、React 子树、辅助技术属性和已展开弹层，不能只替换对象。
- [节点刷新造成输入或焦点丢失] → 优先更新既有节点，回归覆盖代码和公式草稿、焦点及编辑模式；禁止以全面重建视图兜底。
- [初始化期间变化遗漏] → 同步 effect 依赖 loading，验证完成前多次切换只应用最新配置。
- [共享对象导致跨实例污染] → 每个运行时创建独立文案对象，回归覆盖不同语言并存和移除覆盖字段。
- [源码文件已经较长] → 仅评估本次新增刷新职责是否需就近拆分，不以文件行数为由扩展无关重构。

## Migration Plan

保持现有公开属性和默认语言，消费方无需迁移。完成实现后在 README 说明动态切换保留编辑状态及覆盖文案规则。回滚本次同步路径即可恢复原实现，无持久化数据迁移。

验证以规格场景为依据，实施阶段补充针对性回归用例；未获得脚本执行授权时仅进行允许的静态检查并记录未执行项。动态交互验收保留为人工任务，不宣称通过。
