## Purpose

为编辑器代码块提供与语言选择一致的语法高亮，覆盖当前安装的 refractor 版本提供的全部语法及别名，并保证代码内容、语言切换、纯文本及未知语言在导入、编辑和导出过程中的表现一致，避免高亮迁移破坏已有代码块操作。

## ADDED Requirements

### Requirement: 全量语言搜索选择与高亮
系统 SHALL 在编辑器初始化时同步提供当前安装的 refractor 版本支持的全部语法及别名，使其均可搜索、选择并用于代码高亮。语言菜单 SHALL 与实际注册集合一致；此处“全部”不代表支持库尚未提供的语言。

#### Scenario: 全量语言菜单
- **WHEN** 用户打开语言菜单并搜索任一已注册语言或别名
- **THEN** 对应选项可被找到并选择，切换后立即应用对应高亮，不等待额外语法下载

#### Scenario: 默认集合之外的语言
- **WHEN** 导入或将代码块切换为 Dart、Scala 或 Elixir
- **THEN** 各代码块按对应语法高亮，语言标识与源码在 Markdown 往返中保持一致

#### Scenario: 纯文本选项去重
- **WHEN** 全量语言注册完成并生成菜单
- **THEN** 纯文本选项仅出现一次，并沿用当前语言环境的本地化标签

### Requirement: 语言标识直接展示
系统 SHALL 在语言菜单和当前语言按钮中直接显示规范化语言标识及别名，不将其转换为手工配置的展示名；纯文本 SHALL 在这两处使用当前界面语言的国际化文案。此展示调整 SHALL 保持语言值、Markdown 输出和高亮行为不变。

#### Scenario: 语言与别名展示
- **WHEN** 查看或选择 `javascript`、`typescript`、`dart`、`js` 或 `sh`
- **THEN** 菜单与选中后的按钮显示对应标识，不转换为 JavaScript、TypeScript、Dart 或 Shell 等名称

#### Scenario: 大小写无关搜索
- **WHEN** 用户搜索 `DART`
- **THEN** 菜单匹配并显示 `dart`，选择后按钮显示 `dart`

#### Scenario: 纯文本国际化
- **WHEN** 在中文或英文界面查看或选择纯文本
- **THEN** 菜单仅有一个值为 `text` 的选项，菜单与按钮均显示对应界面的纯文本国际化文案

### Requirement: Dart 语言选择与高亮
系统 SHALL 在保留现有可选语言的基础上提供 Dart 选项，并在导入或切换为 Dart 时对代码应用对应语法高亮；语言菜单 SHALL 与实际高亮支持保持一致。

#### Scenario: 导入 Dart 代码块
- **WHEN** 导入包含 `dart` 围栏以及 Dart 关键字、字符串和注释的 Markdown
- **THEN** 代码块使用 Dart 高亮，内容保持原样，语言选择器显示 `dart`

#### Scenario: 从菜单切换到 Dart
- **WHEN** 用户搜索 `dart` 或 `DART` 并选择 `dart` 选项
- **THEN** 当前代码块语言变为 `dart`，立即更新高亮，导出的 Markdown 使用 `dart` 围栏

#### Scenario: 保留已有语言
- **WHEN** 用户加载或选择迁移前支持的语言及其别名
- **THEN** 对应选项和高亮仍然可用

### Requirement: 纯文本和未知语言兼容
系统 SHALL 将纯文本显示为不着色的代码且不因正常纯文本使用产生不支持语言警告；遇到未注册语言 SHALL 保留语言标识和代码内容，不抛出异常或错误应用其他语法。

#### Scenario: 默认或显式纯文本
- **WHEN** 导入无语言代码块或选择纯文本
- **THEN** 代码无语法着色，继续使用现有 `text` 规范化规则，不产生不支持纯文本语言的警告

#### Scenario: 未注册语言往返
- **WHEN** 导入使用未注册语言标识的代码块后导出
- **THEN** 保留经现有规则规范化的语言标识和原代码内容，编辑器可正常使用

### Requirement: 高亮随文档变化更新
系统 SHALL 在代码块内容或语言变化后更新对应高亮，包括多代码块文档、搜索替换及撤销重做；高亮 SHALL 不改变代码文本或污染 Markdown 输出。

#### Scenario: 修改第二个代码块语言
- **WHEN** 在包含多个代码块的文档中切换第二个代码块的语言
- **THEN** 第二个代码块按新语言高亮，其他代码块高亮仍然正确

#### Scenario: 搜索替换未聚焦的代码块
- **WHEN** 焦点位于代码块外并通过搜索替换修改一个或多个代码块文本
- **THEN** 所有受影响代码块的高亮与修改后的内容一致

#### Scenario: 移除关键字后清除旧高亮
- **WHEN** 选区位于段落并将第二个 Dart 代码块内的 `final` 替换为普通标识符 `hello`
- **THEN** `hello` 不保留关键字着色，其他 token 的位置与当前源码一致

#### Scenario: 编辑和撤销重做
- **WHEN** 编辑代码文本并执行撤销或重做
- **THEN** 高亮与每一步恢复后的内容一致，导出仅包含源码和语言信息

### Requirement: 保持代码块现有交互与主题
系统 SHALL 保持复制、代码编辑、HTML/SVG 预览和只读展示行为，并使用编辑器当前明暗主题展示高亮。

#### Scenario: 主题和只读展示
- **WHEN** Dart 或已有语言代码块在明暗主题之间切换或以只读模式展示
- **THEN** 高亮随主题展示且不改变代码块的可编辑性

#### Scenario: 复制及预览
- **WHEN** 复制代码或切换 HTML/SVG 源码与预览
- **THEN** 复制结果为原始源码，预览行为保持不变，返回源码时高亮正确
