## Why

编辑器目前依赖浏览器页面搜索，无法可靠定位结构化文档中的匹配内容，也不能在编辑器实例内完成替换。增加实例级搜索与替换能力，可以让用户在长篇 Markdown 文档中通过熟悉的快捷键高效查找和批量修改内容。

## What Changes

- 在编辑器获得焦点时通过 `Ctrl+F` / `Cmd+F` 打开实例内搜索栏，并在焦点位于编辑器外部时保留浏览器默认搜索行为。
- 支持普通文本、区分大小写、全词和正则表达式搜索，提供全部匹配高亮、当前匹配标识、结果计数及循环的上一项/下一项导航。
- 支持替换当前匹配和一次性全部替换；正则模式支持在替换文本中引用捕获组。
- 每次通过按钮、`Enter` 或 `Shift+Enter` 导航后，基于当前匹配坐标显式调整当前编辑器实例的内部滚动容器，确保匹配完整可见、不会被搜索栏遮挡，且不滚动页面或其他编辑器。
- 搜索在可编辑和只读模式下均可使用，只读模式不允许执行替换。
- 将搜索输入作为主视觉，将大小写、全词和正则选项组织为统一的紧凑分段控制，并统一替换展开、导航、关闭及替换操作的尺寸、圆角、状态和分组；替换输入与操作通过显式按钮渐进展开，完整保留现有能力并降低默认视觉密度。
- 为搜索栏、校验反馈和无障碍标签补充中英文文案及主题化样式。
- 使用成熟的 ProseMirror 搜索能力完成文档匹配和事务更新，不搜索图片、公式渲染结果或代码预览 iframe 的渲染内容。
- 将搜索内核提供的原生 ProseMirror 插件通过 Milkdown `$prose` 适配后注册，修复编辑器初始化阶段的 `plugin is not a function` 错误。

## Capabilities

### New Capabilities

- `editor-search`: 定义编辑器实例内搜索、匹配导航、高亮、正则与全词选项、替换及只读行为。

### Modified Capabilities

无。

## Impact

- 影响 React 编辑器根组件、Milkdown 生命周期 Hook、编辑器运行时和 ProseMirror 插件装配。
- 新增搜索插件、支持替换区展开状态和统一按钮体系的搜索栏组件及独立模块样式，并扩展 `EditorI18nMessages` 中的可覆盖文案。
- 导航定位需要复用当前实例的 EditorView 与 `.zt-md-editor`，通过匹配坐标计算安全可见区域并仅调整该实例的 `scrollTop`。
- 需要在现有 pnpm 依赖生态中引入与当前 ProseMirror 版本兼容的 `prosemirror-search`。
- 搜索插件装配需要遵守 Milkdown 插件函数边界，原生 ProseMirror `Plugin` 不再直接传入 `Editor.use()`。
- README 将补充快捷键、搜索范围、导航滚动、替换区展开方式、只读限制和文案覆盖说明；不引入破坏性公开 API 变更。
